# Architecture decisions

This directory contains the repository's Architecture Decision Records (ADRs). ADR numbering
starts at ADR-009 because earlier decisions were recorded outside this repository; numbering is
kept stable so existing links and issue references remain valid.

Each ADR records the context, decision, consequences, alternatives and status for a significant
architectural choice. Product requirements remain in Jira; an ADR captures the implementation
decision rather than duplicating the backlog.
