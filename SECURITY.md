# Security

Do not open a public issue containing credentials, customer data, exploit payloads or sensitive
vulnerability details. Contact the repository maintainers privately for responsible disclosure.

Automated dependency, secret, workflow-integrity and Python-SAST checks support review but are not
a security certification. Runtime dependency findings block releases unless an exact, approved,
maximum-30-day exception is recorded. Operational details and triage rules are documented in the
[release supply-chain guide](docs/development/supply-chain.md).
